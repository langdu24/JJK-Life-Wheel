# JJK Life Wheel V7 数据系统

V7 的目标不是继续给旧公式打补丁，而是建立一套统一真值：**同一个角色属性，同时决定资源、输出、防御、消耗与长期成长**。

浏览器战斗与自动测试共同调用：

`core/v7-model.js`

`core/v7-data.js` 只负责把这套模型接到现有战斗运行时，不拥有第二套数值真值。

## 1. 统一等级轴

| 等级 | 数值 |
| --- | ---: |
| E- | 0 |
| E | 1 |
| D | 2 |
| C | 3 |
| B | 4 |
| A | 5 |
| S | 6 |
| SS | 7 |
| SSS | 8 |
| EX- | 9 |
| EX | 10 |

EX 不是终点。EX 后第 n 次超越：

`0.24 / (1 + 0.55 × (n - 1))`

因此永远可以继续变强，但边际收益持续下降。

## 2. HP

HP 只由肉体相关属性决定，不再把显性等级、综合战力等重复灌入生命值：

`HP = 140 + 24×体质 + 8×体术 + S以上软超额项`

软超额项：

- 体质：`4 × max(0, 体质-6)^2`
- 体术：`1.75 × max(0, 体术-6)^2`

参考值（体质=体术）：B 268、S 332、SSS 419、EX 552。EX+ 继续增长，无硬上限。

## 3. CE

最大咒力以“咒力总量”为根基：

`CE基础 = 28 + 26×咒力总量 + 8×max(0, 咒力总量-6)^2`

术式威力只提供受限容量奖励：

`min(CE基础×12%, 术式威力×3)`

操纵与效率不会凭空增加最大咒力。零咒力天与咒缚：`CE = 0`。

同等级咒力量与术式威力参考：E- 28、D 86、B 144、S 202、SSS 292、EX 446。

## 4. 咒力效率

B=标准消耗：

`消耗倍率 = exp(-0.105 × (效率 - 4))`

效率只改变“每点咒力能做多少事”，不改变油箱大小。

## 5. 输出轴

物理输出：

`0.68×体术 + 0.32×体质`

术式输出：

`0.46×术式威力 + 0.24×咒力总量 + 0.20×咒力操纵 + 0.10×天赋`

旧战斗引擎的直连卡主要把“术式轴”理解成操纵。V7 适配层只补上缺失的术式威力差值，避免整套术式输出被重复乘两次。

## 6. 防御

体质抗性：

`1.5% + 39% × (1 - exp(-体质 / 11.5))`

它是一条平滑渐近曲线。体术主要参与命中/闪避，不再在命中之后再额外制造一层巨大减伤。

## 7. 通用卡与专用卡

剧情玩家的通用攻击兑现：常规 72%、高输出 80%、明确终结技 90%。

专用直连卡保留自己的卡面数据，但术式类攻击会读取 V7 的真实术式威力。

## 8. 单行动软爆发

不为伏黑甚尔或其它角色设置固定百分比硬上限。

统一曲线的基础阈值：

- 常规行动：34% 最大体势
- 高输出：46%
- 终结技：62%

超过阈值的伤害仍继续增长，只是边际递减。攻击者相对战力越高，阈值和超额保留率越高，因此巨大实力差和真正终结技仍可能秒杀。

## 9. 应用层规则

以下规则属于 `core/v7-app.js`，不是数值核心：

- 剧情敌方难度，默认普通
- SL S1/S2/S3
- 旧 SL key 自动迁移
- 一键车完角色
- 高专地位年龄权重
- 百鬼夜行按当前等级分层匹配
- 属性咒力继续确定具体性质
- 怀玉→0卷时代间成长
- 完整人生结束后的交互锁恢复
- V7 页面品牌与运行状态

应用层禁止复制 HP / CE / 输出 / 抗性 / 软爆发公式。

## 10. 生命周期与兼容层

V7 不再使用永久 50~100ms `setInterval` 扫描。

当前做法：

1. iframe `load` 后按顺序加载 V5、V7 model、V7 data、V7 app；
2. V7 适配器只进行有限次数初始化重试；
3. UI 使用有时限的 `MutationObserver`；
4. 提供 `JJKV7Lifecycle` 事件桥，未来模块可监听：
   - `jjk:v7:ready`
   - `jjk:v7:battle-start`
   - `jjk:v7:wheel-commit`
5. 旧 `monkey-patch` 只保留在尚未拆出的旧 API 边界，随着 `game.html` 模块化逐步删除。

## 11. 存档兼容

V7 当前槽位前缀：

`jjk-life-wheel-sl-slot-v7-`

已知旧版前缀：

`jjk-life-wheel-sl-slot-v1-`

首次启动 V7 时，如果新槽为空，会把可解析的旧 S1/S2/S3 复制到 V7 key，并保存迁移来源。旧 key 不删除，方便回滚。

人生主草稿仍沿用：

`jjk-life-wheel-run-draft-v1`

## 12. 测试

`tests/v7-model.test.js` 覆盖：rank → 数值、HP/CE参考值、低咒力高效率不膨胀CE、零咒力、体质抗性、EX+递减、通用攻击档位、软爆发非硬上限和实力差放宽压缩。

`tests/verify-runtime.js` 检查启动器没有重新加载旧数值补丁。

CI 在部署前必须通过这些测试。

1. `core/v7-model.js`
2. `tests/v7-model.test.js`
3. 本文档

不允许只改文档或只改浏览器适配层。
