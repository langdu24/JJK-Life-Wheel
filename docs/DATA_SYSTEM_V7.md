# JJK Life Wheel V7 数据系统

V7 不再继续给旧公式打补丁，而是提供一套统一真值：**同一个角色属性，同时决定资源、输出、防御、命中、消耗和成长**。旧版 `current.js / v3b.js / v4.js / v6.js` 的数值修正保留作历史记录，但在线入口不再加载。

## 统一等级轴

E-=0、E=1、D=2、C=3、B=4、A=5、S=6、SS=7、SSS=8、EX-=9、EX=10。

EX 不是终点。EX 后第 n 次超越增加：

`0.24 / (1 + 0.55 × (n - 1))`

因此永远可以继续变强，但每次提升越来越小。

## HP

HP 只由肉体相关属性决定，不再把显性等级和综合战力重复灌血：

`HP = 140 + 24×体质 + 8×体术 + S以上的软超额项`

同等级体质/体术参考：E- 140、D 204、B 268、S 332、SSS 419、EX 552。EX 后继续增长，没有硬上限。

## CE

最大咒力以“咒力总量”为根基。操纵和效率不会再凭空把油箱变大：

`CE基础 = 28 + 26×咒力总量 + S以上的渐进超额项`

术式威力只提供最多约 12% 的小幅容量修正。零咒力天与咒缚为 0 CE。

同等级咒力总量/术式威力参考：E- 28、D 86、B 144、S 202、SSS 292、EX 446。

## 咒力效率

B=标准消耗：

`消耗倍率 = exp(-0.105 × (效率 - 4))`

参考：E≈1.37×、B=1.00×、S≈0.81×、SSS≈0.66×、EX≈0.53×。效率降低消耗，但不增加最大咒力。

## 输出轴

物理输出：`0.68×体术 + 0.32×体质`

术式输出：`0.46×术式威力 + 0.24×咒力总量 + 0.20×咒力操纵 + 0.10×天赋`

术式威力不再只是纸面标签；高操纵可以让少量咒力用得更精细，但不会凭空制造巨大 CE。

## 防御

体质抗性采用平滑渐近曲线：

`1.5% + 39% × (1 - exp(-体质 / 11.5))`

约为：D 7.7%、B 13.0%、S 17.4%、SSS 21.0%、EX 24.2%。体术主要参与闪避，不再在命中后重复提供巨额减伤。

## 通用卡与专用角色卡

旧版随机角色的通用攻击常只兑现 45% / 58% 预估伤害，而专用原作角色卡常按完整卡面结算，造成长期偏弱。

V7 的剧情玩家通用卡：常规 72%、高输出 80%、明确终结技 90%。专用直连卡保留自己的卡面数据，但术式伤害会读取真正的“术式威力”。

## 单行动爆发

不再为伏黑甚尔或任何角色设置固定伤害上限。所有角色统一使用软爆发曲线：

- 常规行动：约 34% 最大体势后，超额伤害边际递减
- 高输出：约 46% 后开始递减
- 终结技：约 62% 后才明显递减

实力差越大，压缩越弱。因此同级角色不会频繁被普通一刀随机删除，真正终结技和巨大实力差仍然可以秒杀。没有绝对伤害上限。

## CPU 难度

剧情敌方默认普通；简单/普通/困难由玩家随时切换。玩家方“最佳代理”不再意味着敌方也被强制锁困难。

## 兼容原则

`game.html` 继续提供剧情、人物卡、术式卡、领域、召唤和世界线。V7 只统一“角色数据如何变成战斗数值”的公共层。历史补丁仍在仓库中，但不再参与在线运行。
