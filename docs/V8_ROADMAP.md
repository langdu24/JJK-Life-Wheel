# V8：命运与抉择

V8 的目标不是继续堆更多随机选项，而是让现有角色、能力、战斗、关系与剧情互相产生后果。

核心循环：

随机命运 → 人物底盘 → 执念 → 关键抉择 → 剧情 / 战斗 → 成长 / 伤势 → 经历印记 → 关系变化 → 世界状态变化 → 后续事件权重变化 → 最终人生结算。

核心原则：

- 强度决定你能做到什么。
- 选择决定你愿意做什么。
- 经历决定你后来会怎么做。
- 世界线记录你最终改变了什么。
- 执念点购买机会，不购买胜利。
- 弱角色不等于失败人生。
- 失败本身也是内容。

## V8.0：命运骨架

当前正在落地。

### 1. 人物状态分层

`Base`：初始生成属性。  
`Permanent`：永久伤势、觉醒、束缚、身体改变等。  
`Temporary`：有持续时间的 Buff / Debuff。  
`Current`：最终有效属性。

旧 V7 人生迁移时，已有长期变化先以兼容来源记录，不覆盖 Base。

### 2. 核心世界 Flag

第一版严格限制为 12 个：顺平、真人、五条封印、羂索、宿傩容器、伏黑惠、野蔷薇、东堂、乙骨、死灭回游、天元、宿傩最终状态。

局部剧情不要随意升级成全局 Flag。

### 3. 关键抉择框架

普通事件仍可自动运行。真正重要的历史节点允许玩家亲自选。

一键完整人生遇到 `v8CriticalChoice` 时暂停，不由自动骰替玩家决定。

首个验证节点：涩谷事变。

选择本身只改变后续权重、局部意图、执念进度和可见反馈，不直接判定成功或购买胜利。

### 4. 执念

人物确定后形成一项长期执念。执念有进度、状态和历史。

进度达到 33 / 66 / 100 时获得稀缺执念点。点数上限 5。

执念点未来用于：进入高风险路线、拒绝自动阵营改变、争取救人机会、濒死追加生还判定、传奇挑战、回头。

不得直接加属性、自动赢战斗、自动复活。

### 5. 一致性校验

硬冲突自动修正或生成明确 repair 建议：

- 零咒力天与咒缚 + 正常咒力
- 高级技巧数量与实际列表不一致
- 无生得术式但存在术式
- 未完成领域按完整领域使用

软冲突不删能力，登记为 `世界观异常`。第一条示例规则：海外背景 + 六眼 → `世界观异常：六眼来源不明`。

## V8.1：失败也是人生

计划：

- 经历印记：记忆 / 创伤 / 认知 / 信念 / 心结
- 战败衍生：被俘、被救、失去咒具、永久伤势、欠人情、逃亡、复仇、治疗路线等
- 世界线偏移度与世界稳定度
- 认知差开始积累

目标：即使战败没有属性成长，也能获得信息、关系、心理或路线上的真实内容。

## V8.2：战斗有脑子

计划：

- Build 策略模板
- 玩家战术意图
- 动态 AI 权重
- 客观相性 -3～+3
- 认知差
- 多种战斗目标
- 更完整的领域博弈

战斗目标不再全部等于把敌方 HP 打到 0。

## V8.3：人与人

计划：

- 多维关系：好感、信任、尊敬、恐惧、利用价值、敌意、兴趣
- 关系真正影响支援、追杀、情报、留手、特殊互动
- NPC 死亡余波
- 执念转向
- 关系事件链

## V8.4：完整人生

计划：

- 传奇事件
- 身份专属胜利定义
- 人生摘要
- 最终世界评价
- 最大选择 / 最大遗憾
- 成就 / 特殊结局图鉴
- Seed / 分享码

## 开发纪律

每个新增系统必须至少影响以下之一：人物状态、执念、关系、世界线、传奇事件、最终评价。

不要为了复杂度增加复杂度。不要一开始制造上百个全局 Flag。不要破坏荒诞、随机、容易出现离谱人生的原有乐趣。

V7 战斗数值体系中已经合理的部分继续保留。V8 优先改善“系统是否记住了你做过什么”，而不是重新制造一套伤害公式。
