# JJK Life Wheel

《咒术回战》人生转盘 / 剧情战斗成长闭环的长期维护仓库。

## 在线游玩

仓库使用 GitHub Pages 自动部署。当前稳定版游戏文件统一命名为 `game.html`，根目录 `index.html` 会自动进入游戏。

## 维护约定

- `game.html`：当前稳定可玩版
- `index.html`：GitHub Pages 在线入口
- `releases/`：历史版本归档
- `CHANGELOG.md`：版本与 Bug 修复记录
- GitHub Issues：记录新发现的剧情、世界线、战斗和领域逻辑问题

后续每次修 Bug 或加入新机制，优先保留一个可玩的稳定版，再推进新版本。
